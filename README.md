# Bashasha Secondary School

Online admission and school management system starter for Bashasha Secondary School, Bashasha, Oromia, Ethiopia.

## Included
- Public home page
- Online admission form
- Fayda ID 16-digit validation
- Student result lookup
- Staff login/dashboard UI
- Application/student/subject/mark data model in the frontend prototype
- Responsive green/white/gold design

## Important
This repository contains the frontend implementation/prototype. For production deployment with real authentication, database, file storage, server-side result calculation and Google Sheets OAuth, connect these screens to the Base44 backend/data entities and actions. Do not place OAuth secrets in frontend code.
